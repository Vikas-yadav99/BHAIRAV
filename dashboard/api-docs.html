Core

GET /health

Public health check.
{"status": "ok", "version": "0.17.0"}

POST /api/login Auth

Authenticate, receive JWT.
{"token": "eyJ...", "role": "admin"}

GET /api/status Auth

System status, camera health, evidence counts.
Alerts & Evidence

GET /api/alerts Auth

Recent alerts. Filter by severity, rule, zone, camera.

GET /api/evidence Auth

List evidence clips with filters.
Analytics (Phase 12+18)

GET /api/analytics/summary

Natural-language alert summary.
{"text": "5 critical alerts in Zone A...", "severity": "red"}

GET /api/analytics/hotspots

Ranked risk zones with predictions.
{"hotspots": [{"zone": "Zone A", "risk_score": 0.92, "trend": "rising"}]}

GET /api/analytics/recommendations

Resource allocation recommendations.
{"recommendations": [{"action": "deploy_officer", "priority": "high"}]}
Re-ID (Phase 9+14)

GET /api/reid/similarity

Pairwise cosine similarity matrix.

Incident reports with timeline.
